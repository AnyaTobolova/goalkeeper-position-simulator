# Где стоять вратарю?

Обучающий 2D-симулятор позиционирования футбольного вратаря для детей.
Личный проект: тренажёр для ребёнка ~9 лет и его друзей.

**Игра:** https://keeper.anyatobolova.ru

## Быстрый старт

```bash
npm install
npm run dev      # локальный запуск (http://localhost:5173)
npm run test     # юнит-тесты доменной логики
npm run build    # production-сборка в dist/
```

Стек: Vite + React + TypeScript, статическое SPA без бэкенда. Прогресс — в localStorage, PWA.

## Развёртывание

Развёрнуто на VPS Beget через веб-сервер Caddy (автоматический HTTPS). Обновление — сборка и копирование `dist/` на сервер. Пошагово — в [docs/Обслуживание_и_деплой.md](docs/Обслуживание_и_деплой.md).
